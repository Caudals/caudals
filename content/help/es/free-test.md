La prueba gratuita de [caudals.com](https://caudals.com/es/demo) da una señal rápida y real sobre un asistente antes de crear una cuenta.

## Qué hace {#how}

1. Indicas la página donde se abre tu chat, un endpoint de API compatible con OpenAI o un comando curl (un POST con cuerpo JSON y `{{question}}` donde va el mensaje). Para una API o un comando curl también dices dónde están las respuestas correctas, normalmente tu web.
2. Caudals lee hasta seis páginas públicas de tu web y escribe ocho preguntas, cada una con su respuesta esperada y una cita de la página de la que sale.
3. Hace cada pregunta a tu asistente y califica cada respuesta frente a su fuente.

Suele tardar unos minutos, y la página muestra una estimación. Puedes dejar tu correo para recibir el informe cuando esté listo.

## El informe {#report}

Obtienes el número de respuestas correctas, dónde fallaron las erróneas y cada pregunta con la respuesta de tu asistente, la respuesta esperada y la fuente. Ocho preguntas son una señal, no una medición completa: consulta la [metodología](https://caudals.com/es/metodologia#samples).

El informe tiene un enlace privado. Puedes copiarlo o enviárselo a un compañero por correo. Cualquiera que tenga el enlace puede abrir el informe hasta que se borre.

## Privacidad y límites {#privacy}

- No necesitas cuenta, y el informe se borra siete días después de la prueba.
- Una clave de API o las cabeceras de curl solo se usan para esta prueba y nunca se guardan.
- Cada visitante tiene una prueba gratuita al día.
- La prueba solo hace preguntas corrientes de cliente.

## De la prueba a un espacio {#workspace}

Desde el informe, elige **Crear cuenta gratis** y escribe tu email de trabajo (y, si quieres, tu empresa). Tu nuevo espacio gratuito empieza con el mismo sistema y tu web como material de referencia, listo para un [conjunto de pruebas completo](help:prepare-and-run) de hasta 50 preguntas. Las ocho preguntas de la prueba gratuita se quedan en ella.

También puedes crear un espacio gratuito directamente en app.caudals.com con un email de trabajo, o reservar con nosotros una presentación de resultados desde el informe.
