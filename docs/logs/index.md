# Logs Index

## Folders
- `changelog/`: chronological record of completed work.
- `validations/`: test commands, screenshots, and verification notes.
- `qa/`: targeted QA reports.
- `metrics/`: instrumentation and acceptance check artifacts.

## Logging Policy
- Create a new dated markdown file per meaningful work session.
- Keep files concise; do not build a single large rolling log.
- Link log entries to phase/task IDs whenever possible.
