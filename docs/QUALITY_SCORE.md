# Quality Scorecard

## Purpose
Provide a single quality rubric agents must use before declaring work complete.

## Weighted Score
- Product behavior correctness: 30%
- UX quality and responsiveness: 20%
- Test and validation coverage: 20%
- Reliability and observability: 15%
- Security/compliance posture: 15%

## Scoring Bands
- 90-100: launch-ready
- 75-89: acceptable but needs follow-up hardening
- below 75: not shippable

## Minimum Ship Criteria
- No P0 open defects in touched flows
- Critical path tests passing
- Validation evidence logged
- Docs and plan artifacts updated
