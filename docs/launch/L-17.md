## What shipped

- **Executive summary (P-20).** `lib/evals/reports/summary.ts` builds, from the snapshot's metrics and results only, three sentences in EN/ES through fixed templates (`summary-copy.ts`): "X of Y answers matched your sources (Z%). N more were partly right.", "The main problems are … (n) and … (m).", "Start with: <first fix> (n answers, k critical).", plus the sample line ("Sample: 46 scored answers out of 48 questions.") and the status badges each with a one-line explanation (preliminary/reviewed, complete/incomplete; the example's review is labelled simulated). Every sentence carries the result ids behind it; on the web each has an "Evidence (n)" link that filters the results. A shared copy without results keeps only the metric sentence (its numbers are the metrics; result ids are not shared). Whole-percent headline everywhere (`.p-score`, PDF cover, Word cover); decimals and the Wilson interval moved to Methodology ("Strict pass rate (exact)").
- **Next steps row (P-11, P-20)** under the summary on workspace reports: Book a readout (primary; the `CALCOM_LINK` booking page via `callUrl()` read on the server, with `metadata[source]=report&metadata[workspace]=<12-hex hash of the workspace id>`, new tab, tracked as `readout_link_clicked {surface: report}`), Share and Download PDF (open the heading's own share dialog and PDF export, for the roles that have them), Request expert review (ghost; `caudals.com/{locale}/contact?offer=pilot-evaluation` until L-26; the click tracker records it as `pilot_requested {surface: report}`). The tracker now names the `report` and `share` surfaces.
- **"Fix these first" (P-18).** `lib/evals/reports/fixes.ts` groups failed and partly correct answers by likely cause (else failure category) and by the source page their first excerpt cites, ranks by severity weight (8/4/2/1) then size, and keeps three to five. Each fix: a title ("Update the outdated content behind “Fees and charges 2026”"), "Likely cause (hypothesis): …" or "What went wrong: …", what to do (category actions are the findings' recommendations), evidence link, and a disabled "Re-run these questions" with a visible note (no subset re-run exists; L-18). CSV (one row per answer, formula-safe) and Markdown (recorded text escaped) exports built in the browser.
- **Report tabs.** Test results sort by severity by default ("Failures first" alternative) and "Export failing" (CSV); a result page has "Copy question" and shows the severity badge in the verdict.
- **Share page (P-21).** `/share` adds "What this report is" (method in one paragraph; private, evidence not certification) and, below the report, "Test your own assistant free" to `caudals.com/{locale}/demo?utm_source=shared_report&utm_medium=referral&utm_campaign=report_share&ref=sr-<hash>`. The exchange response gains `meta.referral` (backward compatible; `resolveShareView`). No methodology link: the methodology page arrives with L-20, so it is omitted. The share dialog offers 7, 30 (default) and 90 days and shows "Opened N times, last on …" / "Not opened yet" per link from `share_access_event` views (`open_count`, `last_opened_at` added to the share list; `access_count` kept). The share API is unchanged (any `expiresAt` still accepted; L-21 relies on it).
- **Exports (P-22).** PDF: cover page (brand, system, purpose, dates, status, whole-percent score, KPIs, incomplete caveat), then the executive summary, "Fix these first" and key takeaways, then the existing sections; "Page n of N" on every page (already there). Word: the same order with a page break after the cover and "Page n of N" in the footer. File names `Caudals-<system>-<YYYY-MM-DD>.<ext>` for workspace and shared downloads (`file-name.ts`; accents stripped, safe characters only). Stored PDF/Word files carry the layout version in their path (`.v2.pdf`, `.v2.docx`, `lib/evals/reports/version.ts`) so older files are rendered again on the next request instead of being served (a share PDF rendered in the last ten minutes is served regardless, so an older worker during a rollout cannot loop).
- **Example (L-33).** The in-app example shows the summary (simulated review) and fixes, without next steps or re-run. The sample PDFs were re-rendered with the v2 layout on top of #83's rebuilt Spanish fixture (EN 34 pages, ES 36; manifest updated, `lib/evals/example` gate passes). The public sample page is unchanged.
- **Docs.** `docs/ARCHITECTURE.md` (exports, summary and fixes, share page, events), `docs/FRONTEND.md` (report v2), `docs/DESIGN.md` (`.p-summary`, `.p-fixes`, `.p-share-intro`, `.p-share-cta`).

## Production verification (2026-10-13)

On a published Spanish report of an internal workspace (one member, @caudals.com; 25 results). Only booleans and counts were printed; local copies of the snapshot, PDF and screenshots were deleted afterwards.

- **Worker PDF:** a share-scoped Spanish PDF job (no workspace notification) was rendered by the deployed documents worker in seconds: completed, stored under the `.v2.pdf` path, 55 pages.
- **Web = PDF = Word:** the snapshot rendered by `ReportView` (React server renderer, deployed commit), the worker's PDF (pdftotext) and the Word document carry the same three sentences (every one with result ids), the same sample line and the same whole-percent headline, equal to the metric; the cover has the score, page 2 is the executive summary, every page is "n de N", both fixes are listed. The report's HTML has 0 clipped or overflowing elements at A4 width.
- **Share page:** a bearer link (created for the check, 7 days, all sections) opened headless at 390 px in English and at 1440 px in Spanish (`?lang=es`, PR #80): "What this report is" header, the summary sentences equal to the expected ones, the whole-percent score, the fixes, no next steps for the recipient, the demo link `caudals.com/{en,es}/demo?utm_source=shared_report&utm_medium=referral&utm_campaign=report_share&ref=sr-<hash>` with the workspace's hash, the token gone from the address bar, no horizontal scroll. The owner's list query then returned `open_count` 2 with a fresh `last_opened_at` (`access_count` 2). The link was revoked through the same statements as `revokeShare` (with its `recovery_control_event`); the exchange then answers 404.
- **Public sample report:** `/en/sample-report` and `/es/informe-de-ejemplo` 200 with 48 results each; both PDFs byte-identical to the new manifest (sha256).
- Not checked in production: the signed-in report page itself (no production account is available to agents). It is covered by the harness contracts and by the server render of the production snapshot above.
