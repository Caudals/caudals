## What shipped

- **The example.** One synthetic evaluation of a fictitious insurer, **Hogarel**, and its "Hogar Completo" home-policy assistant: five synthetic source documents (general conditions, FAQ, table of limits, assistance guide, assistant rules), 48 questions in seven topics, and three monthly runs on the same frozen test set (August 54 %, September 65 %, October 76 %). The October report is reviewed-style: executive summary (five takeaways), six findings with likely causes, six improvements with owners and validation plans, and every result with its transcript, expected answer, key facts and cited excerpt. The September → October comparison: 7 improved, 2 regressed, 37 unchanged, 2 not comparable. EN and ES.
- **Fixtures.** Bilingual source in `lib/evals/example/source/*` (`{co}`/`{product}` placeholders, so a rename is one constant); `scripts/evals/build-example-fixtures.ts` builds `lib/evals/example/fixtures/{en,es}.json` with the product's own scoring (`aggregateRun`, `groupFindings`, `pairedComparison`). All three runs are full `reportSnapshotSchema` snapshots; every identifier starts with `example-` and is not a UUID.
- **CI gate.** `lib/evals/example/example.test.ts` (21 checks) runs in the image build (`Dockerfile`, beside `lib/legal`): builder output equals the committed JSON, schema + content hashes, 40–60 results with transcripts and excerpts, every takeaway and finding cites existing results (findings only failed/partial ones), every October failure is covered by a finding, EN/ES structural parity, no real insurer or bank name, no certification or compliance wording, page-copy parity, and the committed PDFs match the fixtures (manifest content hash + sha256).
- **In the app (`/workspace/example`).** Server page reads `EXAMPLE_EVALUATION_ENABLED` and the person's interface language and renders `ExampleEvaluation` (`components/evals/example-evaluation.tsx`) with the same `ReportView`: "Example" pill in the heading, an info banner with the synthetic-data line and the read-only note above every tab, trend and comparison at the top of Overview (a changed question opens that result), Download PDF. No API call of its own. Breadcrumb "Evaluations › Example evaluation".
- **Entry points** (`components/evals/example-evaluation-links.tsx`): a card below the evaluations list (never counted in the filters), a link in the first-evaluation and no-workspace empty states (the action itself for viewers), a Settings → General row. `ExampleEvaluationLink` and `useExampleEvaluation` are exported for L-06 (checklist, empty states) and L-22 (Home). `ShellFrame` gets `features.example` from the server flag.
- **Hiding.** Owners (and operators) can hide the example from a workspace's lists. **Deviation:** the existing "workspace preferences" are per-person notification columns (`evals.notification_preference`); there is no per-workspace preference store without a migration, and this package has none. The choice is therefore stored on the owner's device (`localStorage` `caudals.example-hidden`, per workspace id, like the sidebar state) and the UI says so ("on this device"). L-06's onboarding state (migration 086) is the place to persist it per workspace; swap the storage inside `useExampleEvaluation`.
- **Public page.** `/{locale}/sample-report` (`/es/informe-de-ejemplo`, added to `TRANSLATED_PATHS`), server-rendered Paper page (`components/sample-report/*`, copy in `content/sample-report/{en,es}.json` so it does not enlarge every visitor's message bundle): label at top and bottom, score, trend, comparison, summary, findings, improvements, all 48 results as `<details>`, method, CTA to the demo and a pilot request. No client bundle of its own; a 300-byte inline script opens a result when a `#tN` link targets it.
- **PDF.** `renderReportPdf(..., { sample: true })` adds an "Example" banner on the cover, an Example header line on every page and "Example" in the footer; topic labels in the rates table now wrap instead of being cut with an ellipsis (affects all reports, an improvement). `scripts/evals/render-example-pdfs.ts` renders both PDFs with the document worker's renderer, refuses to write if any table/evidence block overflows A4 or any page lacks the label (pdftotext), and writes `content/sample-report/*.pdf` + `manifest.json` (EN 33 pages, ES 35 pages). Served by `app/sample-report/[file]/route.ts` (404 when the flag is off, `noindex`). `services/evals-documents/render-report.ts` accepts `--locale es` and `--sample`.
- **Sitemap and llms.txt.** The page joins `/page-sitemap.xml` (now explicitly per request) and `/llms.txt` (hourly revalidation) only when `SAMPLE_REPORT_INDEXED=true`.
- **Event.** `example_viewed {surface}` from the consented root tracker: `workspace`, `public`, `pdf`. `analyticsPath` knows the new path segments.
