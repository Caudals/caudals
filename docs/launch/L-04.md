## What shipped

- **One runtime flag, `DEMO_PUBLIC`** (default off, read on the server; `lib/public/front-door.ts`). The spec names `NEXT_PUBLIC_DEMO_PUBLIC`, but the image build only receives `NEXT_PUBLIC_APP_URL`, so a public env flag could not change at runtime (decision I-10 in PROGRESS.md). The `[locale]` layout reads it and hands `{ demoPublic, signInUrl }` to client components through `FrontDoorProvider`; the public tree now revalidates every 300 s (`export const revalidate = 300` on `app/[locale]/layout.tsx`), so prerendered pages follow the flag a few minutes after the app restarts, without a rebuild. Off, every page renders as before.
- **Header**: the pill becomes "Try it free" / "Pruébalo gratis" to `/{locale}/demo`; a quiet "Sign in" / "Iniciar sesión" links to `app.caudals.com/workspace/sign-in`; Contact stays. On phones the pill sits beside the menu button, so the test is one tap from any page.
- **Hero, sector pages, sectors hub, closing card**: the primary CTA is one pill, "Test your assistant free — 8 questions, about 3 minutes" (ES "Prueba gratis tu asistente — 8 preguntas, unos 3 minutos"), to the demo (`components/landing/demo-cta.tsx`). "Or book a 30-minute call" stays secondary. The closing card's line describes the free test and keeps the manual diagnostic one quiet link away ("Rather we run a forty-question diagnostic for you? Request it" → `/contact?offer=reality-check`, with the sector preselected on sector pages).
- **Footer**: "Free test" first and "Sign in" last in Explore.
- **Indexing**: the demo page drops `noindex` while the flag is on (canonical, hreflang and Open Graph from `buildPublicMetadata`), gets its own share card (`app/[locale]/demo/opengraph-image.tsx`, "Free test in 3 minutes. No account."), a sitemap entry after the home page (`lib/seo.ts`), a "Prueba gratuita" line leading "Empezar" in `llms.txt` (revalidate lowered from 3600 to 300 s) and an agent-markdown page (`Accept: text/markdown`).
- **Demo report card (P-07)**: item one reads "Your 8 questions, plus up to 50 more from all your pages". With the flag on: an optional company field (sent as `company`, already accepted by the sign-up route and used as the workspace name), then the CTAs in order: Create free account (primary pill) · Book a readout (ghost pill to `/{locale}/call`, the Cal.com embed configured by `CALCOM_LINK`) · Send to a colleague (text link that opens a small form).
- **Send to a colleague** (`POST /api/demo/runs/:id/share` with a JSON body, `lib/demo/share.ts`): same origin, the run's private token, a finished run and the flag; body `{email, consent: true, key}` (strict). The recipient must be a deliverable address (reserved and disposable domains refused; personal mail allowed). Limits: 5 a day per visitor (HMAC of the IP) and 3 per run over its seven-day life. The sender's consent is recorded first as the server event `demo_report_shared {channel: "email", consent: true}` (hashed run, time, dedupe key per send; it bypasses the analytics rollout flag because it is the consent record); if it cannot be written, nothing is sent. Then exactly one plain-text email (Resend, idempotency key per send) in the run's language: who shared it, the score, the private link, the date the report is deleted, and that the address was not kept. The address is never stored or logged. Without a JSON body the route still acknowledges "Copy private link" as before (L-02).
- **Funnel events**: `demo_signup_requested` (sign-up link, unchanged), `demo_report_shared` (copy and emailed share), `readout_link_clicked` (click to the booking page, surface `demo`/`public`). The click tracker matched only `/en|es/call` and `/en|es/contact`, so Spanish clicks (`/es/llamada`, `/es/contacto`) were never counted; it now resolves translated paths (`lib/analytics/funnel-links.ts`).
- **Docs**: the "soft launch" wording is gone from `AGENTS.md`, `docs/ARCHITECTURE.md` (Public demo) and `docs/FRONTEND.md`.
