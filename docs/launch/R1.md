## Fixes

### Functional

**429s on `GET /api/auth/get-session`.**

- **Cause.** `RootDocument` (every internal page) wrapped the app in an `AuthProvider` that mounted better-auth's `useSession`, and nothing read it (`useAuth()` had no callers). That meant one `get-session` per page load, more on window focus, plus `/api/user/role`.
- **Why it hit the limit.** better-auth's limiter (100 per 10 s per visitor and path) only resets after 10 quiet seconds: `lastRequest` moves on every allowed request. So a steady stream from one address grows the count until it hits 100, then gets 429s for up to 10 s. The QA's two browsers reached it about every 100 loads, which matches the 36 of 934. An office behind one IP would too.
- **Fix.** `lib/auth/session-keep-alive.tsx` replaces the provider. It reads the session at most once per 5 minutes per browser (a timestamp in `localStorage`, try/catch), on load, on becoming visible, and on a 5-minute timer while visible. That keeps the rolling cookie renewal L-24c/L-24d warned about, since `updateAge` is 15 minutes. `lib/auth/provider.tsx` is removed. Server pages and the API check the session themselves.

**Cookie-policy link on the app's 404.**

- `CookieConsentBanner` now uses `LocaleLink`.
- `PublicRoot` takes a `linkOrigin` and wraps the page and the banner in `LinkOriginProvider`.
- `app/global-not-found.tsx` passes the public origin on the app host.
- Result: `https://caudals.com/{en,es}/legal/cookies` on `app.caudals.com`, and the localized path on the public site (no redirect hop).

**Mobile breadcrumb.**

- Each crumb is one line with an ellipsis, and parent crumbs are capped at 16rem.
- Under 640 px only the parent and the current page show.

**Spanish result view overflow.**

- `.p-result-page` has a `minmax(0, 1fr)` column.
- The result toolbar wraps.
- "Prueba 1 de 1" never breaks mid-phrase.

### Shell

- **In-app 404.** `app/(evaluation)/(authenticated)/not-found.tsx` (`AppNotFound`): a `notFound()` inside the signed-in app renders inside the shell ("Page not found", an empty state, "Go to Home") instead of Next's bare 404 outside the app. That covers unknown help articles, flag-off pages, `/review` for non-experts and the top-up 404s.
- **Bell badge.** The unread count sits on the bell's upper-right shoulder with a chrome ring; it used to cover the bell.
- **⌘K.** No clipped focus ring on the palette's own field. Item names win over their grey context, which is capped at 45% with an ellipsis.
- **Session-expired banner (kit-level).** `Status` actions wrap onto their own line before the sentence drops below 12rem. On a phone this banner had read one word per line.
- **Drawer.** The mobile navigation drawer has a "Close navigation" button.
- **Skip link.** Its shadow no longer peeks into the top bar.
- **ES.** The switcher heading reads "Espacios de trabajo".

### Lists

**`DataTable stack`** (kit; documented in `docs/DESIGN.md` §7):

- Under 640 px each row stacks: the title and the row's actions on the first line, then the other cells.
- Cells are labelled with `data-label` where a bare value would be ambiguous. Lone dashes (`data-empty`) are hidden.
- Applied to Evaluations, Systems and Test sets, whose row menus and "Check now" were off-screen behind a sideways scroll.
- Desktop is unchanged.
- R2 built the same kit option for Reports. Both branches carry the identical `DataTable` signature and CSS block, so whichever merges second has no conflict. R1 adds only `data-empty` and `data-actions="wide"` (Systems), in a separate block.

### Workspace Home and the evaluations list

- **No duplicate step line.** `nextStepHint`: no second line when the stage badge already names the step ("Generate the test set" twice; "Add reference material" plus "Add your reference pages…").
- **Zero count.** Home hides the "0" count on "Needs your action".
- **Keyboard hint.** The ⌘K hint is hidden on touch-only devices.
- **Empty workspace.** The welcome, the empty state and the checklist are spaced as a stack. Under the empty state, the checklist's steps are secondary, so the page has one primary action.

### Evaluation page

- **No score.** With nothing scored, "0 of 0 answers correct" is no longer printed under "No score yet".
- **Comparison headline.** "Score —, was 100%." became "No score in this run; was 100%." (EN and ES; identical to R2's fix).
- **Singular re-run.** "re-runs the 1 questions" / "las 1 preguntas" became a singular sentence.
- **Not found.** "Evaluation not found" offers "All evaluations".
- **Cancelled runs.** A cancelled run offers "Run again" to editors and owners when the test set is approved. Same path as the failed state.
- **Connect step.** The back button's arrow points back.
- **Help link at 390 px.** On Prepare tests, the lone "?" help link stays beside its section title.
