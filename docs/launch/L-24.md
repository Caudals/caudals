**Performance (P-47)**
- **Demo proof of work fixed.** Production minified the worker's `search` function, so every worker threw `search is not defined` and every visitor solved the 18-bit challenge on the main thread in 20,000-hash slices while the page loaded (mobile TBT 4,227 and 47,347 ms in two runs; L-04's "236–6,256 ms"). The worker is now built from one self-contained kernel read back by property name; it starts when the visitor engages with the form (focus, tap or typing) and the fallback works in ≤ 8 ms slices. Not weakened: same 18 bits, signature, binding and single use. `lib/demo/demo.test.ts` runs the worker source from an esbuild-minified bundle. Production check: no worker at load, a worker on focus, a nonce in 866 ms, no error.
- **Demo start view server-rendered.** It rendered only after hydration, so the LCP element was the footer and the content pushed it down (CLS 0.113). Now the headline is the LCP element and CLS is 0; a run's private link hides the start view before the first paint (inline script, `html[data-demo-run]`).

## Not met, and why

- **LCP < 2.5 s on mobile for the landing and the demo**, and **TBT < 200 ms on mobile for the landing** (220–256 ms: hydrating the whole client-rendered landing and evaluating both language catalogs). Lighthouse's simulated LCP counts every byte loaded before the first paint, and the shared public frame loads ~330 KB of fonts (Newsreader with its optical-size axis is 279 KB of that) and ~350 KB of compressed script (React and Next, Sentry, both language catalogs, the header's sheet). Experiments on a local copy of the production landing: removing all font preloads alone made it worse; small fonts plus no fade 4.2–5.0 s; small fonts and about 100 KB less script 3.3–3.7 s; no script at all 3.3 s. Meeting them needs a public-site weight package: per-locale message bundles, server-rendered landing sections with small client islands, the mobile menu loaded on open, and the Newsreader axis decision (§5). Desktop LCP is 1.3–1.4 s. The demo's first question at p50 (P-47) is measurable from the next demo runs (docs/TOOLS.md).
