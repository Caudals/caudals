## 2. What changed

Kit (`components/evals/primitives.tsx`, `packages/brand/platform.css`, documented in DESIGN.md §7 and §9):
- `TabStrip` (`tab-strip.tsx`) behind `Tabs` and `TabLinks`: the current tab scrolls into view on a narrow screen and the end with more tabs fades (`data-overflow`). The billing console's views are pill `TabLinks`, so the two tab rows read as levels.
- `EmptyState compact` for an empty table inside a section (replaces bare grey sentences in Platform, the billing console and the review queue).
- `formatMoney()` formats in the interface language with the currency symbol; `formatEuros()`. `formatDate()` reads a calendar day (`2026-10-01`) at noon UTC, so it names the same day in every time zone.
- `humanize()` keeps acronyms in English ("API question"); Spanish for the codes operators read routinely is in the phrase table (run events, judge and review reasons, engine roles, probes, data policy, growth sources, amendment kinds). STATUS tones for review requests, price-book revisions, built-in packs and model-health failures.
- CSS: `.p-stats-note`, `.p-toolbar-note`, `.p-cell-nowrap`, `th.p-cell-wide`, `.p-link-external`, `.p-judge-calibration`; dates and ids never wrap in tables; definition lists stack on phones and cap at 48rem; page-heading actions drop below the text on phones and `h1` breaks between words; side-panel body columns `minmax(0, 1fr)`; spacing after stat strips and after a heading inside `p-stack`.

Screens:
- **Overview:** each stat strip in its own section ("Growth · last 7 days", "Demo health", "Client work"); demo failure reasons as words (`demo-reasons.ts`); "1 stuck run"; next step from the stage projection (no more "Generate the test set" next to "Waiting for reference material"), nothing repeated for work in flight; "≤ 5 min".

- **Growth:** counts right-aligned, weeks as "Week of 12 Oct 2026", reasons, sources, help reasons and stages labelled, accounts without a company show the email domain or "Unnamed account", section help as descriptions.
- **Review queue:** reasons labelled; the judge's pending placeholder ("Waiting for the answer judge.") in Spanish through `engineText()`; compact empty states; reason left-aligned; question titles keep 14rem at 390 px.
- **Run inspector:** plurals; euros everywhere; the timeline to the second; plan fields labelled, hashes shortened alike with the full value on hover; the rubric judge as pills plus a calibration sentence.
- **Library:** rights and task types labelled; built-in pack titles and summaries in Spanish; sector-pack breadcrumb; draft pill neutral; sector help beside its Import action; "Spain · Spanish".
- **Prospects:** the list reads each link's grant (revoked or expired shows as such); "Link revoked", "1 view"; Warmbly text labels translated; external links keep their icon; the policy list is bulleted with space before the confirmation.
- **Expert work:** singular keys; delivered/declined tones; the client context only on the per-client tabs; rows link to the request; ids as codes; the intro only while a request is open; "Under 1 h".
- **Platform:** adapter names and prices per 1M tokens from the catalogue, short revision ids, data policy labelled, probe noun, amendment diffs labelled, plurals, currency on settled/reserved, credit usage labelled "All workspaces", member search, roles as pills, audit log with an action filter, absolute times and short ids.
