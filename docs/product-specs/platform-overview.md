# Platform Overview Spec

## Problem
ML teams need scalable, quality-controlled data collection with operational visibility and reliable payouts.

## Product
Caudals connects requesters, contributors, and admins to run dataset operations end-to-end.

## Primary Outcomes
- Faster dataset throughput
- Higher data quality via review loops
- Reliable contributor payout lifecycle
- Auditable operations for enterprise trust

## Scope
- Marketing/public funnel
- Auth and role onboarding
- Role applications (`requester`, `contributor`, `admin`)
- Payment and export operations

## Non-Goals (Current)
- Major PWA redesign
- Dark mode rollout
