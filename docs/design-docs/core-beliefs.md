# Core Design Beliefs

## Product Experience Principles
1. Operational clarity beats decorative complexity.
2. Critical actions must be obvious and reversible when possible.
3. Dense data views should stay readable under time pressure.
4. Role-specific workflows should never look interchangeable.
5. Trust signals (status, payout state, review state) must always be visible.

## Visual Principles
- Light neutral canvas with strong content hierarchy.
- White surfaces, soft borders, deliberate contrast for actions.
- Green accent reserved for positive states and key highlights.
- Dark primary CTAs for high-intent actions.

## Interaction Principles
- Fast feedback for every user action.
- Explicit empty/loading/error states.
- Keyboard and screen-reader access in core workflows.
- Mobile behavior must preserve same information architecture logic.
