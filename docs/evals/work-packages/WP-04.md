# WP-04 — API systems and structured imports

Status: deployed. API targets have workspace-managed credentials, and frozen text conversations run through the API run endpoint when the connection check has verified multi-turn support.

## Delivered

- `lib/evals/connectors`: OpenAI-compatible, provider-native and declarative HTTPS JSON contracts; fixed JSON selectors; per-target concurrency/RPM bounds; public-HTTPS validation; DNS answer-set rejection; and socket pinning. Redirects are not followed, so a redirect cannot bypass destination validation.
- Target revisions hold immutable, secret-free connector configuration. Credentials remain envelope encrypted and target-scoped. `targetInvocationSecret` decrypts only for the matching live, fenced `target_attempt`.
- `createTargetAwareRun` freezes the target/config hash, suite and exact case revisions. Text-only single-turn deployed-system work is queued durably. `TargetExecutionWorker` writes immutable observations, projects actionable target/transport/unsupported outcomes, fences completions, and marks a killed post-dispatch attempt `unknown_external_outcome` without replay.
- Migration 046 requires a tenant-scoped target invocation usage reservation before a target attempt can enter `dispatching`. The worker reserves bounded inputs/outputs, enforces target concurrency and requests per minute across replicas, records reported usage, and holds unknown outcomes for review. Customer-owned endpoint tariffs remain externally billed and unknown to Caudals; their calls are separate from the platform cash budget.
- Connection checks persist capability/configuration evidence. An execution response distinguishes bad credentials and invalid response mappings from model failures.
- CSV/XLSX/JSONL imports retain original rows and row errors. XLSX macros, external links, embeddings and formulas without cached values are rejected. Source hashes plus mapping versions detect duplicate imports.
- Candidate answer templates contain only case identity, revision identity and candidate input. Manual/imported observations preserve unavailable usage, latency, cost and model identity as unknown rather than zero.

## Operator/API contract

- Create immutable target revision: `POST /api/evals/v1/projects/:projectId/targets`.
- Check its bounded configuration/capability surface: `POST /api/evals/v1/targets/:revisionId/checks`.
- Preview/import: `POST /api/evals/v1/imports`; inspect with `GET /imports/:id`; apply answers with `POST /imports/:id/apply`.
- Download candidate-only CSV/JSONL: `GET /suites/:suiteId/candidate-template?orgId=…&format=csv|jsonl`.
- Start execution/imported-response run: `POST /api/evals/v1/runs`; inspect with `GET /runs/:id`.

Target API dispatch requires the general worker with an explicit workspace allowlist. The connector never receives provider/DGX secrets. Website, browser and private-runner kinds remain honest unsupported Stage C/D paths.
