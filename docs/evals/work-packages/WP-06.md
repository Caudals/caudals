# WP-06 — Scoring, adjudication and aggregation

Status: deployed. Deterministic graders and the calibrated rubric-judge path run in production. Judge results that are not calibrated stay in human review.

## Delivered

- Deterministic exact, decimal, claims and bounded JSON-schema graders distinguish model outcomes from target/transport/capture failures. Tool-state, rubric-judge and human requirements never become an automatic pass; unresolved checks are unscorable and enter review.
- Judge packets treat candidate output as untrusted data and grant no tools, network or secrets. Model, prompt and calibration revisions are part of the CEF grader contract.
- `POST /api/evals/v1/runs/:id/score` appends assessments without calling the target. Regrading appends a superseding assessment; previous evidence remains immutable.
- `POST /api/evals/v1/assessments/:id/review` records approve/dispute decisions or an attributed human override with a required reason and immutable replacement assessment.
- Aggregation reports planned/eligible/executed/scorable/pass/partial/fail/unscorable/pending/unresolved denominators, assessed coverage, completion, missing-result bounds, Wilson intervals and family-cluster intervals. Zero scorable results yields no accuracy. Critical missing results make the headline incomplete.
- Failure grouping is evidence-linked and labels causes as hypotheses unless directly supported. Comparisons require the same frozen suite/case family, rubrics, scorer, candidate context, tool fixtures, repetition policy and execution conditions.

## API contract

- Score/regrade: `POST /runs/:id/score`.
- Review/override: `POST /assessments/:id/review`.
- Frozen paired comparison: `POST /comparisons`.

The current automated release path is deterministic-first. Rubric-judge cases remain in `needs_review` unless a versioned judge result or human override is appended; the implementation deliberately does not convert missing judge infrastructure into a pass.

## Verification

Fixtures exercise pass, fail, operational-unscorable, unresolved judge, attributed override, zero/low coverage, clustered uncertainty and incompatible rubric comparison. Full database tests verify immutable results and assessments under RLS.
