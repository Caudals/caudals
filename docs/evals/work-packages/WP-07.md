# WP-07 — Reports, exports and private delivery

Status: document worker deployed for the existing evaluation workspaces; PDF generation and visual inspection from a production report remain a release gate.

## Delivered

- Reports are immutable typed snapshots: system/scope, exact denominators, findings, result evidence, improvements, methodology, frozen IDs, review status and limitations. Narrative takeaways are derived only from snapshot findings; narrative failure does not block the deterministic report.
- Workspace report UI provides overview, findings, result transcript/evidence, improvements and methodology tabs from that one snapshot. Trusted HTML rendering escapes candidate text and uses print-safe headers, wrapping and page-break rules.
- CSV neutralizes spreadsheet formula prefixes and distinguishes empty values from numeric zero. CEF export is JSONL containing a checksum manifest plus the exact case, observation and assessment documents—not a renamed report JSON object.
- PDF requests create durable `export_job` rows. `services/evals-documents/main.ts` claims only explicit workspaces, recovers stale render-only work, renders in isolated Chromium, stores private checked artifacts and emits one deduplicated completion notification. Report/scoring work is not retried when rendering fails.
- Publication switches only the report's current immutable revision and emits a deduplicated in-app notification. Prior revisions do not mutate.
- Bearer shares use 256-bit URL-safe tokens stored only as hashes, bounded expiry, report-revision scope, allowlisted projection fields, access audit and immediate revocation. Only grants explicitly marked `bearer` resolve through the public exchange. The token is read from the URL fragment, exchanged by same-origin POST, then removed from browser history. Share routes send no-referrer/no-store/noindex/CSP headers and expose no mutation API or private object URL.

## API contract

- Create/read/publish: `/api/evals/v1/reports`, `/reports/:id`, `/reports/:id/publish`.
- Queue PDF or create CSV/CEF artifact: `POST /exports`; authenticated bytes stream through `/report-artifacts/:id` after a fresh authorization check.
- Create/revoke a share: `/reports/:id/shares`, `/shares/:id`; exchange bearer token: `/share/exchange`.

Workspace and named-recipient access use authenticated workspace/report authorization. A named-recipient token is deliberately not accepted by the bearer exchange.
