## 🚀 How to Use

### Step 1: Run Migrations

In Supabase SQL Editor:

```sql
-- Run the admin system migration
-- Copy/paste: supabase/migrations/002_admin_system.sql
```

### Step 2: Create Admin User

```sql
-- Replace with your user ID
UPDATE profiles
SET role = 'admin'
WHERE id = 'your-user-id';
```

Find your ID:

```sql
SELECT id, email FROM auth.users;
```

### Step 3: Test Flows

**As Requester:**

1. Go to `/dashboard/requests/new`
2. Create a dataset request
3. Check `/admin/requests` as admin

**As Admin:**

1. Go to `/admin`
2. Approve the request
3. Verify it appears in `/browse`

**As Contributor:**

1. Browse datasets at `/browse`
2. Click on a dataset
3. Contribute files
4. Check `/admin/submissions` as admin
