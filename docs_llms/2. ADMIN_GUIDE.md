# Admin System Guide

## Overview

The platform now includes a complete admin approval system where administrators can review and approve:

- Dataset requests from businesses/researchers
- Contributions from users

## Setting Up an Admin User

### Option 1: Via SQL (Recommended)

Run this in Supabase SQL Editor to make a user an admin:

```sql
UPDATE profiles
SET role = 'admin'
WHERE id = 'user-id-here';
```

To find your user ID:

```sql
SELECT id, email FROM auth.users;
```

### Option 2: Via Dashboard

1. Go to Supabase Dashboard → Authentication → Users
2. Find the user and copy their ID
3. Go to Table Editor → profiles
4. Find the row with that ID
5. Change `role` to `admin`

## Admin Features

### Admin Dashboard (`/admin`)

Access at: `http://localhost:3000/admin`

Shows:

- Pending dataset requests count
- Pending submissions count
- Approved datasets count
- Total users count
- Quick action buttons

### Review Dataset Requests (`/admin/requests`)

**What it does:**

- Lists all pending dataset requests
- Shows request details (title, requester, category, samples, reward)
- Approve or reject with notes

**Workflow:**

1. Click eye icon to view full details
2. Click green checkmark to approve
3. Click red X to reject (must provide reason)
4. Approved requests appear in browse feed
5. Rejected requests are hidden with notes sent to requester

### Review Submissions (`/admin/submissions`)

**What it does:**

- Lists all pending user contributions
- Shows dataset, contributor, files count
- Approve or reject submissions

**Workflow:**

1. Review file submissions
2. Approve quality submissions (increments sample count)
3. Reject poor quality with feedback
4. Approved submissions earn contributors rewards

## Complete User Flows

### Flow 1: Business Posts Dataset Request

1. Business signs up / logs in
2. Goes to Dashboard → New Request
3. Fills multi-step form
4. Submits (status: pending approval)
5. **Admin reviews in `/admin/requests`**
6. **Admin approves → appears in browse feed**
7. Business monitors in their dashboard

### Flow 2: User Contributes to Dataset

1. User browses approved datasets at `/browse`
2. Clicks "Contribute Now" on a dataset
3. Views full details at `/browse/[id]`
4. Uploads files with notes
5. Submission status: pending
6. **Admin reviews in `/admin/submissions`**
7. **Admin approves → user earns reward**
8. Sample count increments

### Flow 3: Admin Management

1. Admin logs in
2. Goes to `/admin`
3. Reviews pending items
4. Approves/rejects with feedback
5. Monitors platform activity
6. Manages user roles if needed

## Database Structure

### New Tables

**admin_activity_log**

- Tracks all admin actions
- Records approvals/rejections
- Includes notes and timestamps

### New Columns

**dataset_requests:**

- `approval_status` - pending/approved/rejected
- `admin_notes` - feedback from admin
- `approved_by` - admin user ID
- `approved_at` - approval timestamp

### Updated Policies

- Only admins can view pending requests
- Only admins can update approval status
- Only approved datasets show in browse
- Requesters can see their own pending requests

## Running the Migrations

1. Run `002_admin_system.sql` in Supabase SQL Editor
2. Create storage buckets (if not done)
3. Set an admin user (see above)
4. Test the flows

## Security

- Admin routes protected by middleware
- RLS policies enforce admin-only access
- Activity log tracks all admin actions
- Rejection reasons stored for transparency

## Common Tasks

### Make User an Admin

```sql
UPDATE profiles SET role = 'admin' WHERE id = 'user-id';
```

### View Pending Requests

```sql
SELECT * FROM dataset_requests WHERE approval_status = 'pending';
```

### View Admin Activity

```sql
SELECT * FROM admin_activity_log ORDER BY created_at DESC LIMIT 20;
```

### Approve Request Manually

```sql
UPDATE dataset_requests
SET approval_status = 'approved',
    approved_by = 'admin-user-id',
    approved_at = NOW()
WHERE id = 'request-id';
```

## Troubleshooting

### Can't Access Admin Dashboard

- Check if your role is 'admin' in profiles table
- Clear browser cache
- Sign out and sign in again

### Requests Not Showing

- Check `approval_status` is 'approved' for browse
- Verify RLS policies are enabled
- Check browser console for errors

### Files Not Uploading

- Verify storage buckets exist
- Check RLS policies on storage
- Ensure user is authenticated

## File Organization

Uploaded files are organized as:

```
dataset-files/
  └── {dataset_id}/
      └── {user_id}/
          └── {timestamp}_{filename}
```

This keeps contributions organized by dataset and contributor for easy management.
